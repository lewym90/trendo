# Trendo

Moda, trendy, stylizacje i zakupy w jednym miejscu. PWA do instalacji na ekranie startowym telefonu.

Wersja 0.1.0: cały interfejs działa na **danych przykładowych** (`js/demo.js`), oznaczonych w aplikacji. Prawdziwe dane ze sklepów dostarczy serwer (osobny etap).

Zasady:
- AI nigdy nie podaje produktów, cen ani linków z głowy. Produkty pochodzą tylko z danych sklepów.
- Promocje są sprawdzane z najniższą ceną z 30 dni przed obniżką (Omnibus) i z historią cen serwera.
- Każdy trend ma źródła, a prognoza jest oznaczona jako prognoza.
